The problem

Two learners from the game plan tried one online lesson on 21 October.

Hana

  • Deaf, Ethiopian Sign Language
  • Adama

Dawit

  • Blind, TalkBack
  • Bahir Dar
  • No captions. No signer.
  • Buttons without labels.
  • Nothing offline.

Hana and Dawit are personas from the game plan, not people we met.

The idea

  • One lesson script
  • Machines draft the captions
  • A named person approves
  • Only approved text reaches a learner

Next: the main task, live.

The main task, live

  • A Savanna page: starter files not edited
  • Amharic captions, then play
  • At two minutes the video pauses; the description goes to the screen reader
  • Check question, then a certificate link: Verified, no name on it
  • Job card: three-line summary, Ethiopian date

Sign window: labelled placeholder, not an interpreter.

One lesson, many outputs

Learner

  • Captions: Amharic, English
  • Transcript
  • Descriptions
  • Braille file

Slow phone

  • 8 KB offline lesson
  • Data saver
  • No video until asked

Pipeline

  • One real 90 s video
  • 13 drafts
  • 1 mistake: “A I” heard as “A E I”

So a person approves every line.

Adoption

  • One script tag, 34 KB gzipped
  • Or a blank page with plain files, no server
  • REST API and an OpenAPI file
  • One docker compose up
  • Nothing leaves the host: no CDN, no analytics
