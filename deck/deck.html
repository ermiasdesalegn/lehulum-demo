Lehulum (ለሁሉም)

Accessible learning media for every learner: captions, sign language, audio description, Braille and offline lessons from one lesson script.

One online lesson, two learners shut out

We followed two learners from the game plan through the same lesson.

Hana, Adama

  • Deaf, uses Ethiopian Sign Language
  • No captions, no signer
  • Cannot follow the lesson

Dawit, Bahir Dar

  • Blind, uses TalkBack
  • Buttons without names
  • Cannot start the video

Both

  • Nothing works offline
  • Heavy video on a slow phone
  • No Amharic in the interface

Hana and Dawit are personas from the game plan, not people we met.

The idea: one script, every way in

1. One script

  • The instructor writes the lesson once

2. Machines draft

  • Captions, translation, audio-only version

3. A person approves

  • Every line has a named reviewer

4. Learners get it

  • Only approved text reaches a learner

Why a person: our pipeline heard “A I” as “A E I”. Machines help; people decide.

Try it now: live, no login

  • Lesson 1 player captions in Amharic and English, sign window, audio description at 2:00
  • Lesson 2 player a real 90-second video with its sign-language track
  • Instructor Studio add a lecture and a sign video, watch them stay in sync, review captions

Keyboard only works everywhere. At two minutes the video pauses and the description goes to the learner's own screen reader.

One lesson, many outputs

For each learner

  • Captions: Amharic, English
  • Movable sign-language window
  • Audio description, transcript
  • Tagged PDF and Braille file

For a slow phone

  • 8 KB offline lesson
  • Audio-only 64 kbps version
  • Data saver: no video until asked

For the instructor

  • One real 90 s video in, 13 caption drafts out
  • Review table, one click to approve
  • Job card with spoken summary

Easy to adopt, easy to trust

Adopt it

  • One script tag, 37 KB gzipped
  • Or plain files, no server
  • REST API and OpenAPI file
  • One docker compose up

Trust it

  • 259 unit, 320 API and 51 browser tests pass
  • Automated axe checks clean in every state tested
  • Nothing leaves the host: no CDN, no analytics
